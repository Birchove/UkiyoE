浮世微言 · 本地预览操作说明
================================================

【一、前提】
确认已安装 Node.js(版本需 ≥ 18.17,本项目在 Node 22 上验证)。
在终端运行  node -v  能看到版本号即可。

  若用 nvm 管理 Node,先切换到可用版本,例如:
      nvm use 22


【二、首次使用:安装依赖(只需一次)】
进入项目目录,执行:

      cd /mnt/d/toys/浮世微言
      npm install


【三、启动预览(二选一)】

  ▍方式 A:开发预览 —— 推荐
    改动内容或样式会自动刷新,适合边写边看。

      npm run dev

    终端出现  Local  http://localhost:4321/  后,
    用浏览器打开: http://localhost:4321
    结束预览:回到终端按  Ctrl + C

  ▍方式 B:构建后预览 —— 与线上部署效果一致
    适合发布前最终核对。

      npm run build       (生成 dist/ 静态文件;WSL 下约 40~70 秒)
      npm run preview

    同样打开: http://localhost:4321


【四、看不到内容?逐一排查】

  1. 端口被占用(默认 4321)。可换端口启动:
         npm run dev -- --port 4322
     然后访问 http://localhost:4322

  2. 新写的条目不显示。只有 frontmatter 里
         status: "published"
     的条目才会上站;草稿(在 _drafts/ 或 status 非 published)不会显示。

  3. 提示找不到 node / npm 命令。确认 Node 已安装并加入了 PATH;
     nvm 用户请先  nvm use 22  再执行。

  4. 改了内容页面没变。方式 A 会自动刷新;方式 B 需重新  npm run build。


【五、常用命令速查】

      npm run dev        启动开发预览(热更新,最常用)
      npm run build      构建静态站到 dist/(部署前用)
      npm run preview    预览构建产物
