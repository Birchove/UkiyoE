本文件夹下, 我想做一个现代版的民间史网站. 起名叫"浮世微言". 英文仓库名/网站名就叫 UkiyoE

1. 类似于<世说新语>, <笑林广记>, <西京杂记>, <东京梦华录>, <小窗幽记> 等这些古典笔记小说的表述方式. 有诙谐幽默, 有深刻箴言, 有市井烟火....
2. 第一要义还是要真实客观, 因为首先的定位是"史", 要有多方面多视角的记录和评价
3. 网站分页分栏展示, 要有不同版面
4. 整体资源上传github开源库, 后续我会部署到github page(无需cc部署)
5. 信息来源是爬取知乎热搜, 微博热搜, 等其他热搜; 但是注意要过滤 花边新闻, 政治新闻, 无意义的热搜; 我会补充一个筛选原则的文档
6. 网站的名称为"浮世微言", 所以需要像太史公写史记一样, 除了记录事件本身, 还要有一段总结评价的话语;
7. 记录事件本身应客观克制, 不含情绪评价, 若有争议, 需要有多方面多角度的记录, 使用白话文
8. 总结评价的话语可以有情绪化表述, 可以褒贬, 使用半白半文言
9. 部分新闻媒体的文章也可以参考, 但是原则相同
